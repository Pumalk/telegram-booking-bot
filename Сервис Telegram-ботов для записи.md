# Сервис Telegram-ботов для записи

Дата изменения: 12.10.2026  
Источник актуальных фактов: `всякая фигня.md` + содержимое страницы репозитория `telegram-booking-bot`.

---

## 1. Общая идея

Это платформа для малого бизнеса: маникюр, брови, репетиторы, массаж и подобные услуги.

Целевая архитектура:

- единое ядро / backend;
- множество клиентов-мастеров;
- общий код не меняется при подключении нового мастера;
- настройка клиента делается через YAML;
- бот принимает записи, отправляет напоминания, показывает услуги, контакты и отзывы.

Текущий статус:

- ✅ есть рабочий локальный шаблон бота;
- 🕒 полноценная мультиклиентская платформа ещё не доведена до продакшена;
- 🕒 предоплата и онлайн-календарь пока заглушки;
- ✅ Telegram-транспорт требует отдельного решения из-за доступа к Bot API из России.

## 2. Текущая реализация

Один базовый бот для записи клиентов.

Сценарий и настройки мастера разделены:

- `config/ниши/бровист.yaml`
- `config/ниши/маникюр.yaml` — примеры шаблонов.
- `config/клиенты/анна-брови/конфиг.example.yaml` — безопасный пример настройки клиента.

Принцип подключения нового мастера:

- общий код не меняется;
- копируется папка клиента;
- папке задаётся уникальный латинский идентификатор;
- редактируется YAML.

## 3. Установка и запуск

### 3.1 Python

- Установите Python 3.11 или новее.
- При установке отметьте добавление Python в PATH.

### 3.2 Конфиг клиента

В папке:

```text
config/клиенты/анна-брови
```

скопируйте:

```text
конфиг.example.yaml
```

и назовите копию:

```text
конфиг.yaml
```

### 3.3 Telegram-бот

1. Откройте Telegram.
2. Найдите `@BotFather`.
3. Отправьте `/newbot`.
4. Выполните подсказки.
5. Скопируйте выданный токен.

### 3.4 ID мастера

Узнайте свой числовой Telegram ID через бота-информатора.

### 3.5 Заполнение конфига

Откройте `конфиг.yaml` в Блокноте или редакторе текста.

Нужно заполнить:

- токен бота;
- свой числовой ID вместо демонстрационного `0`;
- название;
- услуги;
- расписание;
- контакты.

Значение `клиент` оставьте:

```text
anna-brovi
```

или замените на уникальную метку латиницей, цифрами, дефисом или подчёркиванием.

### 3.6 Запуск через BAT

Дважды щёлкните:

```text
запустить-бота.bat
```

При первом запуске файл создаст виртуальное окружение и установит зависимости. Нужен интернет.

При последующих запусках установка пропускается.

### 3.7 Запуск из консоли

В этой папке используйте:

```bash
python run.py
```

Для другого файла клиента:

```bash
python run.py --config "config/клиенты/папка-клиента/конфиг.yaml"
```

Эту же опцию можно передать BAT-файлу.

## 4. Поля конфигурации

### `токен_бота`

Секретный токен, выданный официальным `@BotFather`.

Правила:

- не публиковать;
- не отправлять посторонним;
- хранить только в локальном конфиге или secure storage.

### `админы`

Список числовых Telegram ID мастеров.

Нужно:

- узнать свой ID у бота-информатора;
- заменить демонстрационный `0`.

### `клиент`

Уникальная метка:

- латиница;
- цифры;
- дефис;
- подчёркивание.

По ней создаётся файл базы.

Важно:

- не использовать один ID у разных клиентов.

### `ниша`

Имя YAML-файла в `config/ниши` без расширения.

### `услуги`

Для каждой услуги:

- название;
- цена;
- длительность в минутах;
- `включена: true/false`.

### `запись`

Рабочие дни:

- `пн`
- `вт`
- `ср`
- `чт`
- `пт`
- `сб`
- `вс`

Часы:

```text
ЧЧ:ММ-ЧЧ:ММ
```

Шаг слота.

### Другие поля

- `адрес`
- `контакты`
- `отзывы`
- тексты приветствия
- описание

Замените демонстрационные значения на актуальные.

Важно:

- сохраните файл и перезапустите бота после изменения настроек;
- YAML чувствителен к отступам;
- используйте пробелы, не табуляцию.

## 5. Команды администратора

Команды доступны только Telegram ID из поля `админы`.

- `/help` — показать справку.
- `/bookings` — список ближайших активных записей.
- `/block_day 2026-10-05` — закрыть день. Вместо даты можно указать `сегодня` или `завтра`.
- `/open_day 2026-10-05` — снова открыть день и снять блокировки его слотов.
- `/block_slot 2026-10-05 18:00` — закрыть конкретное время.
- `/open_slot 2026-10-05 18:00` — открыть конкретное время.
- `/cancel 3` — отменить запись по номеру из `/bookings`; клиенту отправится уведомление.

Форматы:

- дата: `ГГГГ-ММ-ДД`
- время: 24-часовой формат.

## 6. База данных и время

### SQLite

База создаётся автоматически в соседней папке:

```text
data/<клиент>.sqlite3
```

Не удаляйте этот файл:

- в нём хранятся записи;
- блокировки расписания.

Для резервной копии:

1. остановите бота;
2. скопируйте файл базы.

### Время

Время записей соответствует локальному времени компьютера, на котором запущен бот.

Нужно:

- настроить правильный часовой пояс Windows.

### Напоминания

Напоминания проверяются примерно раз в минуту.

Важно:

- бот должен быть включён;
- при выключенном ПК напоминания не гарантируются.

### Хранение данных

Данные остаются локально на компьютере.

Это:

- не облачная БД;
- не резервное хранилище.

## 12. Telegram Gateway и доступ к Bot API

Это критический внешний слой для платформы.

Проблема:

- нужен стабильный доступ к Telegram Bot API из России, Улан-Удэ.

Не подходит:

- `tg-ws-proxy`, потому что он работает с MTProto, а не с HTTP Bot API.

Текущее архитектурное решение:

```text
Python Backend
    ↓
Telegram Gateway
    ↓
api.telegram.org
```

Основной кандидат:

- ✅ Cloudflare Worker.

Альтернатива на будущее:

- 🕒 Local Telegram Bot API Server в Docker с собственным прокси/VPN.

Статус:

- окончательного выбора нет;
- Cloudflare Worker — основной рассматриваемый вариант;
- Local Bot API отложен.
