# Telegram-бот записи — Тариф 1

Один базовый бот для записи клиентов. Сценарий и настройки мастера разделены:

- `config/ниши/бровист.yaml` и `config/ниши/маникюр.yaml` — примеры шаблонов.
- `config/клиенты/анна-брови/конфиг.example.yaml` — безопасный пример настройки клиента.
- Общий код не меняется при подключении другого мастера: скопируйте папку клиента, задайте ей уникальный латинский идентификатор и отредактируйте YAML.

## Запуск на Windows

1. Установите Python 3.11 или новее и при установке отметьте добавление Python в PATH.
2. В папке `config/клиенты/анна-брови` скопируйте `конфиг.example.yaml` и назовите копию `конфиг.yaml`.
3. В Telegram откройте `@BotFather`, отправьте `/newbot`, выполните подсказки и скопируйте выданный токен.
4. Узнайте свой числовой Telegram ID через бота-информатора.
5. Откройте `конфиг.yaml` в Блокноте или редакторе текста. Вставьте токен и свой ID вместо демонстрационного `0`; настройте название, услуги, расписание и контакты. Значение `клиент` оставьте `anna-brovi` или замените на уникальную метку латиницей/цифрами/дефисом.
6. Дважды щёлкните `запустить-бота.bat`. При первом запуске файл создаст виртуальное окружение и установит зависимости; нужен интернет. При последующих запусках установка пропускается.
7. Найдите своего бота в Telegram и отправьте `/start`. Окно с ботом должно оставаться открытым: пока бот выключен, он не принимает записи и не отправляет напоминания.

Для запуска из консоли в этой папке используйте `python run.py`. Для другого файла клиента: `python run.py --config "config/клиенты/папка-клиента/конфиг.yaml"`; эту же опцию можно передать BAT-файлу.

## Что изменить в YAML клиента

- `токен_бота`: секретный токен, выданный официальным `@BotFather`. Не публикуйте его и не отправляйте посторонним.
- `админы`: список числовых Telegram ID мастеров. Узнайте свой ID у бота-информатора; замените демонстрационный `0`.
- `клиент`: уникальная метка латиницей, цифрами, дефисом или подчёркиванием; по ней создаётся файл базы. Не используйте один ID у разных клиентов.
- `ниша`: имя YAML-файла в `config/ниши` без расширения.
- `услуги`: название, цена, длительность в минутах и `включена: true/false`.
- `запись`: рабочие дни (`пн`, `вт`, `ср`, `чт`, `пт`, `сб`, `вс`), часы (`ЧЧ:ММ-ЧЧ:ММ`) и шаг слота.
- `адрес`, `контакты`, `отзывы`, тексты приветствия и описание: замените демонстрационные значения на актуальные.

Сохраните файл и перезапустите бота после изменения настроек. YAML чувствителен к отступам: используйте пробелы, не табуляцию.

## Команды мастера

Команды доступны только Telegram ID из поля `админы`:

- `/help` — показать справку.
- `/bookings` — список ближайших активных записей.
- `/block_day 2026-10-05` — закрыть день; вместо даты можно указать `сегодня` или `завтра`.
- `/open_day 2026-10-05` — снова открыть день и снять блокировки его слотов.
- `/block_slot 2026-10-05 18:00` / `/open_slot 2026-10-05 18:00` — закрыть/открыть конкретное время.
- `/cancel 3` — отменить запись по номеру из `/bookings`; клиенту отправится уведомление.

Используйте формат даты `ГГГГ-ММ-ДД` и 24-часовой формат времени.

## Данные и важные ограничения

- База SQLite создаётся автоматически в соседней папке `data/<клиент>.sqlite3`. Не удаляйте этот файл: в нём хранятся записи и блокировки расписания. Для резервной копии остановите бота и скопируйте файл.
- Время записей соответствует локальному времени компьютера, на котором запущен бот. Настройте правильный часовой пояс Windows.
- Напоминания проверяются примерно раз в минуту. Бот должен быть включён; при выключенном ПК напоминания не гарантируются.
- Данные остаются локально на этом компьютере; это не облачная БД и не резервное хранилище.
- **Предоплата — заглушка:** бот не принимает платежи, не отправляет реквизиты и не подтверждает оплату.
- **Онлайн-календарь — заглушка:** свободные окна считаются только по расписанию, записям и блокировкам в локальной БД.
- Перед передачей клиенту настройте и проверьте конфиг, токен, ID мастера, услуги и контакты на реальном тестовом Telegram-боте.

## Проверка без Telegram

В этой папке выполните:

```powershell
python _smoke_test.py
```

Проверяются загрузка YAML, запись и защита от пересечений в SQLite, слоты расписания, напоминания и тексты.

## Реализовано и отложено

**Реализовано:** приветствие; кнопочное меню «Записаться», «Прайс», «Отзывы», «Контакты»; выбор услуги, даты и времени с подтверждением; локальная SQLite; блокировка пересекающихся записей; закрытие/открытие дней и слотов; уведомление мастера о новой записи; напоминания за 24 и 2 часа; конфиги ниши и клиента; запуск через Windows BAT.

**Отложено/заглушки:** приём и подтверждение предоплаты; подключение Google/Яндекс-календаря; облачный хостинг и постоянная работа без включённого компьютера; автоматическая синхронизация между несколькими устройствами; автоматическое получение отзывов и каталог фотографий.
